# 处方草案 · 发布作业物理隔离（催生 INCIDENT-20261001 三度主树手术; 待人类逐字批准入宪）
## 拟增条款（L-ENGINE-ISOLATION 段扩展）
+ # L-RELEASE-TREE-ISOLATION（发布树隔离律 — 事故催生 2026-10-01）
+ - 发布物化（orphan 支、排除清单、rsync/git archive 镜像、release commit/tag 制作）**只准在隔离 checkout 内进行**（专用目录或 /tmp clone）; 内网主工作树禁止 \`git switch --orphan\`、禁止任何 \`--delete\` 语义的同步命令指向树内、禁止 rm 树外无锚路径之外的批量删除。
+ - 主树 = 考卷与证据的活体面; 发布面 = 隔离 clone 内的派生物。两者唯一合法耦合 = git 远端对象库, 永不为共享工作目录。
+ - 跨席作业声明: 对同一物理目录, 执行席动树前须声明(账本行), 他席见声明即避; 无声明的树面重写 = 与伪造回执同级(毁他席作业面)。
+ - 发布提交必须 content-only orphan(无内网谱系), 从**最新已验发布基线**在隔离面生成; 主树遗留的分支手术残渣(如 be57e14)一律不得作为发布面, 由纪委席具名标废。
