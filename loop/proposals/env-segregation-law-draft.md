## 0. 两套坐标系 + 判定域

- **进程判定类别**（判序输出全集，v6 must-fix 8 措辞修正）：E0 / E1 / 机主（持键人，非违规主体）/ 出域（冻结清单命中，不判）/ DISPUTED（写冻结待裁）。E0/E1 的判据见 §1。
- **面分类**（写到哪）：E0 面（/tmp run 目录、fake-HOME）、E1 面（主树、.omo/evidence、loop/、座席自装服务的 workspace 家）、**Q 面**（隔离发布 checkout）、E2 面、E3 面。
- **判定域 = 本机全部进程，减去「出域宿主服务冻结清单」**（v4 must-fix 1，取修法 A）。冻结清单是**封闭枚举工件**：机器状态快照 + sha256 戳；非座席安装的 sshd、mongodb、系统级 systemd 单元等入列（示例为说明性，权威以快照为准）；「等非代理进程」式开放类别**禁用**（cron 注入可钻，v4 must-fix 2）。**快照规范形态（v6 must-fix 2）**：只取稳定字段子集——单元名、可执行路径、包版本或二进制哈希——排序规范化后计 sha256，比对键 = 该规范化快照（PID、时间戳等易变字段不入哈希，否则重比门永久失配）。**两类失配处置**：快照多出条目（新增服务）→ fail-closed 域内处理 + 具名伤单；清单有条目而快照无（缺失服务）→ 同 fail-closed + 具名伤单；均走人类门修订后才放行出域。**完整性锚（v5 must-fix 1/5 + v6 must-fix 6）**：权威形态 = L-STATE-ATOMIC 追加式哈希链账本条目（前项哈希入后项），规范化快照 + 其 sha256 入账，**锚定于人类签署条目**；账本落点 = `.omo/evidence/` 哈希链账本（E1 面），E1 证据面其余位置只许存副本，不作权威；整册替换 = 断链事件，机械可检出。账本自身无机器外更强锚——具名缺口 G7 在册，不谎称根除。**判序①命中校验的可机判谓词**：判定方每次 campaign 前重跑规范化快照，与账本最新人类签署条目登记的 sha256 比对；不一致 → fail-closed，全部进程按域内处理（逃逸者仍落判序⑤）。座席重写 E1 副本在复算下机械可检，拿不到脱身券。清单修订 = 新快照 + 新哈希链条目 + 人类签署，走本律修订同门。**座席自装的 crontab 项（例：消毒代理看门狗）不属于出域宿主服务**（v4 must-fix 3）：自装即自有工件面，可归因、可回退，仍在本律判定域内，其类别按归因条款的安装者继承规则判定（见下条）。
- **归因条款（v4 must-fix 2 + v5 must-fix 4/6 + v6 must-fix 4，能力型封闭定义）**：**域外服务以任意时序执行域内进程所提供数据的任何机制**（「任意时序」含即时与延迟，堵死「事件驱动不算延迟」的辩称空间，v6 must-fix 4），其后续写入**归因于提供/安装该上下文的域内进程本身**——借宿主服务之手出域 ≠ 脱责。机制封闭枚举（八项）：crontab 项、systemd-user 单元、rc 钩、DB 存储执行、队列消费、wiki 渲染执行、文件监视/事件触发、进程间消息总线；枚举修订走人类门（能力定义兜底，枚举用于举证）。**安装者类别继承（v5 must-fix 4）**：域内进程安装的执行上下文，其后续写入按安装者类别继承判定（E1 座席装的 → 归 E1；E0 候选装的 → 归 E0）；**安装者登记条目（v6 must-fix 7）**入同一哈希链账本，必备字段 = 安装工件路径 / 单元名 / crontab 条目原文、安装时刻、安装会话 ID——「哪条 cron 属于谁」的归因举证链按此闭合，字段不齐 = 举证不闭合 = 按安装时在场类别从严。自装服务（如消毒代理看门狗写 workspace 日志）因此不被误判为 E0 违规体。
- **机主进程正判定谓词**（不是默认豁免）：登录 uid=机主 + 交互 TTY 会话在场 + 非任何座席/跑器进程的后代。三条全真才是机主进程。**具名残余风险与出口（v5 must-fix 2 + v6 must-fix 1/5 + v7/v8 定稿修订）**：uid=机主、非座席/跑器后代、但**无交互 TTY**（GUI/文件管理器/桌面服务等途径）的进程三条件不全真——此类进程**不得直接按 E0 违规主体定罪**，改落 **DISPUTED = 写冻结待裁态**：待裁期间该进程对 **E1/E2/Q 面**的写入一律拒止或回滚（写冻结含 Q 面，v7 评审：发布 checkout 可被污染，不得漏列；**执行主体具名**，v8 must-fix 4：uid=机主进程不在座席写路径上，「拒止」为条款级——事后回滚 + 哈希链检出，无机械拦截，不谎称），机主具名正声明（终端一句话确认）即出列。**防逃逸排除条件（v6 must-fix 1，谓词机判化 v7）**：**活跃 campaign 窗口** = 跑器台账启动条目至收束条目之间（机判定义，v7 must-fix）；**人类在册启动证据** = **人类签署的哈希链条目**（L-STATE-ATOMIC：非人类签署登记无效，机判依据具名）。窗口内新出现、且无人类签署条目的进程**不得入 DISPUTED**，直落判序⑤——逃逸者不能借机主 uid 领免罪窗口（v8 定稿：散文与谓词统一，不再带「早于该窗口」限定；判序清单+机判谓词为唯一权威）。可机判谓词 = `uid==机主 ∧ 非②③命中 ∧ 无 TTY ∧ 非归因继承命中 ∧ 非（窗口内新生且无人类签署条目）` → DISPUTED（v8 must-fix 1：安装者为域内进程的上下文产物按安装者类别判定，不入 DISPUTED——自装看门狗不被谓词字面误捕）。**落⑤机主 uid 进程的降级通道（v7 must-fix，目标类别钉死 v8 must-fix 3）**：默认 fail-closed 不降级；机主终端一句话确认 + 登记人类签署哈希链条目后，**正条目登记即视同该进程的具名正声明，判为机主（非违规主体）**——机主 campaign 期间临时 GUI 启动不会被永久误判。**批量清道（v6 must-fix 5，匹配谓词收紧 v7，载荷钉住 v8 must-fix 2）**：机主自有周期进程（自有 crontab 项、systemd-user 单元）可由人类签署的哈希链条目按单元名/cron 项登记；其后实例**匹配谓词 = 同名 ∧ 可执行路径/指令原文哈希与登记条目一致 ∧ 无安装者登记冲突 ∧ 指令所引用载荷不位于座席可写面**——四全真才按判序④出列（载荷在座席可写面的单元不适用批次出列，防登记后改写脚本冒充机主逃逸）；**同名冒充排除**：凡安装者登记条目在册且安装者为域内进程的单元名，批次出列不适用。**优先级声明（v7 must-fix）：归因条款的安装者类别继承优先于判序④批次名匹配与④b**——冲突时按安装者继承判定，fail-closed。**「谁可落⑤」唯一定义（v7 must-fix，三席同点矛盾修复）**：判序清单 + 机判谓词为唯一权威——**①–④b 全部不命中 → ⑤**，不分 uid；uid=机主 ∧ 无 TTY ∧ campaign 窗口新生无证者按此明确落⑤（其降级通道见上）。机主进程在域内，由判序④/④b 出列，非默认豁免（v4 must-fix 8 复核确认）。
- **判序（固定）**：①判定域外（冻结清单命中，校验谓词见上）→ 不判；②跑器台账命中或祖先命中 → E0；③座席会话派生 → E1；④机主正判定（三条件全真）**或账本名登批次命中**（谓词：同名 ∧ 可执行路径/指令原文哈希与人类签署登记条目一致 ∧ 无安装者登记冲突 ∧ 载荷不位于座席可写面；与归因条款冲突时安装者继承优先）→ 机主（持键人，非违规主体）；④b 机主 uid 无 TTY 且非归因继承命中且非 campaign 窗口新生无证 → DISPUTED 写冻结待裁；⑤**①–④b 全部不命中** → **最严类（E0 写规则）**——含机主 uid 窗口新生无证者（有人类确认降级通道：签署条目登记即视同正声明判为机主，默认不降级）。豁免永不默认适用于归不了类的进程。

## 3. 唯一合法晋升路径 + 禁令清单

```
E0 候选 → 检疫(提名, 仍在 E0 面) → 人类 promote → E1 面(主树)
  → Q 面(独立 clone)制作发布件 → 边检门 → 人类 push/tag → E3 → 人类安装已发布件 → E2
```

禁令（逐条具名）：
- **E1→E2 直通安装**（dev-link 事故真形）：禁止 `npm link -g`、禁止从任何工作树 `npm i -g`；冻结全局只准从 E3 已发布件更新。
- **E0→E3 令牌直通**：持测试令牌把 E0 产物直推云端 = 非法（条款级，具名缺口 G4）。
- **E0 进程→E2 面**：零写通道。
- **E1→E3 绕门**：发布不经 Q 面 + 边检 + 人类键 = 非法（发布树隔离律已闸，引用不重述）。
- 跳过任何人类门 = 越权，与伪造同罪。

边界豁免（封闭清单）：
- `git worktree add/remove` 写主树 `.git/worktrees/` 元数据：边界允许（E0/E1 内部耦合，见 §2 调和段）。
- E0 运行证据由跑器侧（E1）归档进 `loop-archive/`、`.omo/evidence/`；考生自己不写 E1。
- 座席经 historian_* 工具写 `_evidence/**`、`_meta/**`：合法，见共享服务表。

## 4. 凭证规则

从无权写的面读取凭证再跨环境行动 = 按读取者的环境类别归因判定。E0 进程永远不得持有评分键、生产写令牌、E2 面秘密。机主 2026-10-19 授权的生产令牌（百炼/vLLM）= **测试流量授权**，形态 = 专用/限额/可吊销/逐 run 登记的密钥；扩写面非法。
