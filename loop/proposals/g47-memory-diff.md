# g47 memory-diff — 两律入宪提案（世代 G47；案源：西比拉 v1.3.x 战役实录 2026-10-15，锚循环一支已由条款七收编，SR4-64 已由它题化——本diff只补remaining两缺口）

## 条款八：链失败即停（CHAIN-ABORT）

- 凡"步骤 N 的产物是步骤 N+1 的前提"的多步变更命令（写文件→提交→打标签→部署），必须
  逐步执行、每步落一张非零即停的回执；单条串联长命令（`a && b && c` 里塞 heredoc 长程序）
  在步间无回执=禁止形态——一次事故在案: python 段崩于中途, 同链 `git commit`/`git tag`
  照跑, 错版标签铸在未修补面上（本机销毁重铸, 未出机, 全程在册）。
- 长程序（>10 行的内联脚本）一律先落成文件再调用; 内联段只准短探测。
- 链上任何一步失败后: 下游全部中止、现场只读勘察、失败点具名上报后才许续链。跳过勘察
  直接重放全链=对已知伤员补刀, 与伪造回执同罪族。

## 条款九：就地勘误（IN-PLACE-ERRATA）

- 已流通文本中被证实为假的陈述, 勘误必须落在**该陈述所在的同一行段**（就地标注/取代式
  改写+日期注记）; 只在文末追加更正段而正文原样留存=未尽义务。判据: 只读正文任一节的
  新读者, 不被引导到勘误, 即视为该假陈述仍在其面上流通。
- 不可动面（已发布 tag 对象体、已上架包、追加式账本的既往行）按律不改写, 但必须在
  其最近的**可动对应面**就地标注+具名指向不可动原文的位置——"不可动"免责止步于该面本身。
- 删除假陈述而不留勘误轨迹=改写记录; 与伪造同罪族。案源: 004f 判例——"Docs-only wheel"
  错标在被本文件自己的更正段承认四天后仍以原形挂在正文标题位。
