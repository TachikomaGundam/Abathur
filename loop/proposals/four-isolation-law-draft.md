## 2. 裁决链

1. 合约封存：C 开工前验收合约经独立审计方封存；『A 链』=**起草会话谱系**（引擎可对账的会话链，L-BLIND-AUDIT 标识对账），盲审方须与该谱系非亲缘——且 **spawn 源须为人类启动的会话**（『引擎根会话』歧义封堵：座席发起的 sibyl 新生会话**不算**根会话）；引擎 DB 与锚链同 uid 可写——同威胁模型下 DB 对账在 R-ISO-3/G7 闭合前降为 advisory，或盲审 spawn 回执须人类带外签名。
2. C 产出哈希链回执；C↔A 无共享可写路径。
3. 裁决权转移条款：**自 R-ISO-1 机主批准后生效**——批准后通过/不通过裁决权归盲审方，A 只观察活性并搬运结果。
4. **R-ISO-1（待人类裁决）**：『A 观察但不裁判』是对机主原话『由 A 来进行观察、监督、反馈』的具名重释（监督/反馈按字面可含裁判权）。**未裁前 interim 态：裁决权按原话全义仍在 A，盲审道作为复核与异议通道运行；§2.3 不先生效**。

## 4. 回滚路径

A 面回滚=人类重装上一已发布版；**留存义务入条款**：每次发布时对上一版 tarball 算哈希并存具名持久面（发布收据+.omo/release/）留回执——替代不可证的『缓存优先』；发布前 `npm view <pkg>@<旧版>` 实跑留回执（样例：2026-10-22T23:26:59Z 版本序列 0.2.0…0.3.0 可见）。npm 语义（https://docs.npmjs.com/policies/unpublish，访问日 2026-10-23）：发布 72h 窗内可 unpublish，窗外仅 deprecate。若旧版已被 unpublish：**唯一正道=留存面 tarball（.omo/release/）+对留存哈希校验**；缓存副本仅在哈希校验通过后可作降级备援，校验不过=触发 manifest 重锚人类门；git tag 重建件非字节一致→同走重锚人类门。两难如实并列，由人类选。A 面数据/台账=追加式无回滚；配置损伤=备份复原。

## 5.5 时序判据的时钟锚（v7 降级）：追加式链只保证**提交序**不保证**事件序**（延迟落账可伪造『晚于』）。涉时序条目强制引用外部观察者（封存戳/外锚）；**降级范围仅覆盖追加链排序类判断**（条目先后次序）；**同步原子检查不降级**（publish 前一刻重比、D 门原子读、安装后即比对——它们不依赖链序，依赖当场复算）。
