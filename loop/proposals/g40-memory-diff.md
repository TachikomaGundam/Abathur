+ # L-BIDIRECTIONAL-AUDIT（双向闭合律 — G40 新增）
+ - 对一组主张的复核必须双向：**soundness**（上屏每条→地面）与 **completeness**（地面每行→上屏或入豁免表）。配对准则分两类：主张↔账目行=（行锚+逐字摘录）；主张↔文件工件=复用 L-BLIND-AUDIT 的（证据路径,sha256）逐字配对。只出单侧=复核不成立；两表残差皆零且配对回执在账，才准进入 L-BLIND-AUDIT『验证通过』态——本律不新增出口词汇。
+ - **地面锚（含时效配对）**：审计开始前具名声明地面行集（绝对路径+行范围+取数时刻）并当场按哈希复算；**入账与交付两个时点均须以同一锚重算并配对，以后一时点为准——任一失配=审计作废、按新锚重跑**；对共享可变面的审计强制走封印快照分支（具封印哈希，沿 L-STATE-ATOMIC 先例）。该配对是 L-BLIND-AUDIT『验证通过』态的必要条件。声明地面≠地面，复算先行；缩小声明面或抢在写法未终的活面上闭账以造零残差=与伪造回执同罪族。
+ - **派生事实有界入册**：审计面=验收合约逐字列出的派生量，或审计前按推导方案预枚举入账的派生清单。推导方案=对地面行单层派生（求和/求差/存在性断言）——派生的派生不入审计面（一次闭包，不递归）。枚举内漏项=残差；枚举外不得事后追指作废已闭审计，但**转为具名新伤单/新题接工序二收口**（发现即入账，不作豁免）。合约逐字未列派生量而审计者自带清单时：清单须经人类具名认可入账，否则判『合约缺派生量清单=合约缺陷』登记送裁（防『少枚举=多免责』棘轮）。
+ - **豁免表反空转**：每格豁免须引用合约条款号作范围外依据；豁免占比分母=地面行集声明锚内总行数；阈值关系**单向**——合约只准在默认 20% 之下收紧、不得放宽，合约声明阈值高于 20%=合约缺陷登记送裁（与『检索广度无 N=合约缺陷』『阶梯未声明=送裁』同款出口）；豁免行本身入 soundness 审计面。
+ - 两张对账表（含具名豁免列）计算并存档于**内部面**——completeness 的豁免记录不上人面，与本律和 L-ABSENCE-SILENCE 的留白要求互不冲突；人类面呈现形态依 L-ABSENCE-SILENCE 死锁解除链（留白+缺口节总述）。

+ - 建在抽取数据上的闸门使用前必须按类通过**丢失测试**。结构类=封闭枚举四项：①相邻行续接（split runs）②表格断行 ③脚注/尾注按语 ④内嵌媒体引用；条文不以『等』开放。
