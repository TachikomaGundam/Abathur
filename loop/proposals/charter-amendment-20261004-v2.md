## 术语（唯一定义处，他处只准引用）
- **身份锚**：花名册条目（name+email+key fingerprint，L-STATE-ATOMIC 注册链，人类签署条目背书）。session_id 只是辅助字段。
- **执行链**：引擎 DB 可对账的父子/发起关系（sid 换号不断链）；「同链」判定=两 sid 间存在链路径。
- **器具（instrument）**：门/尺/考卷/宪法条款的受版本控制工件；instrument_id=其内容 git blob 谱系根+全部版本 sha 集。
- **裁决周期**：loop 道=[seed_item 起, bundle_close 止]；门道=[config/规则写入起, 下一次 landing/PASS 记录止]；无界即视为永不结束（fail-closed）。
- **冷却窗 W=2 个裁决周期**（全典唯一定义处；A1 与 B3 均引用此行）。

## A0 分立授权（内联，消 v1 悬空引用）
紧急兼程唯一路：机主签署的账本条目逐案点将，条目须引用可复算的签署凭据（花名册 key 对账），并写明 期限+器具+范围 三限定；任一缺失=伪造，视同无授权。授权入链后兼程者仍受事后盲审追认。

## A1 兼职禁止律（L-INCOMPATIBLE-OFFICE）
1. 修复≠认证（**永久，无时间窗**）：对器具 I 有 author/repair 记录（**同执行链**，任一版本）的身份，永不得出 I 的健康/验收证书。
2. 修器者判卷禁：身份锚同链曾 author/repair I，且某裁决的**所用器具登记表**含 I ⇒ 该裁决席违规——判据主体是「器具→所判工件范围」隶属表，不再比对工件集相交（v1 核心漏边，封死）。
3. 每份裁决条目强制字段：(identity, role∈封闭枚举{author,repairer,judge,certifier,reporter}, instrument_ids[], artifact_sha256[], chain_ids[])。**任一字段缺失=违规成立（fail-closed）**；角色自署无效，须引擎 DB 对账派生。
4. 换会话/换 sid 不豁免：判据按执行链合并计算；「同链」不成立方视为独立席，独立性断言须附 DB 对账回执。
5. 评审资格冷却：I 之修复者对 I 所辖工件的 judge 角色，自修复时刻起经 W 后恢复（引用术语节 W）；certifier 角色不恢复（第 1 款永久）。

## A2 宪法分层（L-NORM-STACK）
1. 全局核心律 vs 项目附律两级。**附律无核心源可溯即无效**（v1 病句方向已改）；lint=白名单制：仅显式标 `global:` 的条款行可存在于全局文件，项目条款混入=装载失败；「项目专属」判定不靠词法黑名单（改名即绕，v1 判），改靠条款头的 `project:` 强制字段+文件归属双查。
2. `derived_from:` 必须解析到**存在的**核心条款号，装配器逐条核销；解析失败=该附律无效并不阻断他条（错误隔离）。
3. 注解允许（查士丁尼禁令之败为鉴）但**注解内出现规则差分=覆写**，覆写须显式 `amends:` 申报并走机主批，静默覆写按伪造回执论。
4. AGENTS.md 全局段=**人类专属面**（道主表登记为 human-only），座席仅可按既有批准程序追加晋升条款头，不得改写既有条款文本。

## A3 管辖路由（L-JURISDICTION-ROUTING）
1. 上位调和（明文字面）：已晋升的 L-GOVERNANCE-REMEDY（就地修复跨道义务）**优先于本条**——本条不得被援引为拒绝修复的理由；跨道修复的合法通道=道主表登记的**工单授权**（授权条目引用申请与批准双条目，随工单路由），无工单的他道写入才判违规。旧宪不受新律证伪：本条与其冲突处一律以旧宪为准并出修订请求。
2. 道主表：路径前缀→道主（身份锚）；座席临时工作区有默认道（本席 scratch 自动归属，防全卡人类签署之瘫）；未覆盖路径写入=fail-closed：不入仓、落隔离区、自动生成挂账工单（既非静默放行亦非全量禁写）；lint 断言无歧义嵌套前缀。
3. `superseded-by` 只准 **核心→附 单向**，附律永不得向上覆写；装配器断言声明图无环；成环=两声明同时作废并呈人。
4. 唯一有效裁决：同 artifact_sha256 出现第二纸互斥裁决 ⇒ 第二纸自动 DISPUTED 呈机主，禁各自执行（v1 有义务无判据，今补牙）。
5. 冲突计数=滚动 30 日窗口；机械识别器：条目 (path∈道 A 辖区) ∧ (author 链∉道 A 花名册且无 A3.1 工单) 为一冲突；≥3 ⇒ 该面进拆分评审，评审由机主或独立席执行，**涉事道主不得自审**。

## A4 托管回执（L-CUSTODY-RECEIPT）
1. 共享权威面（门配置/钉票集/账本状态文件）每写必落**哈希链回执**：条目含 {前像 sha256, 后像 sha256, 写者身份锚+链, 时刻}；**回执 N 的前像必须等于回执 N-1 的后像**，不符=DISPUTED；并发写以链序裁决，禁以「当前值==某张回执」的单指针校验（v1 分叉漏，封死）。
2. 可恢复引用只准指向**追加式账本存储内的内容寻址对象**（blob 随回执入库），禁以可删改 ref/tag 为唯一引用；回执写入时断言对象可读（防空引用假安全）。
3. 执法点改判：pre-commit 钩子=便利品**非安全边界**；违规判定=事后审计脚本对整链重算（断链/缺回执/混 lane 即红），脚本身份独立于被审写入席。
4. 对账覆盖面：开机+夜扫对**全部权威面（含非 git 面）**做「当前哈希 vs 回执链末端」比对。
5. 灾备具名：门配置裸 git 的**第二介质由机主点名**（默认：/home/lab/workspace/debug/ 下镜像+月度 sha 抽验）；机主亦可签署「接受丢失风险」声明替代。

2. 类戳生时盖：{永久证据|战役期|瞬时}；**永久→战役降级或 TTL 删除，条目必须引用人类签署条目或盲审通过收据**（堵合法毁证通道）；数值：战役期 TTL=30 日、瞬时=24h、永久件只准落白名单路径集（.omo/evidence/**、loop-archive/**）。
