# 宪章修正案草案 · 分权与管辖（2026-10-04 生产事故的后案法典化）
状态=提案，未生效。来源=六份制度史卷宗（见文末索引），事故卷宗=.omo/evidence/INCIDENT-20261004-session-entanglement.md。
总根因判词（罗马经验）：**把仲裁者写进运动员的名单，字再对也白写**——分层与分权必须落成文件面与能力面的物理隔离，不能只落在义务文字上。

## A1 兼职禁止律（L-INCOMPATIBLE-OFFICE）｜原型：美宪法 Art I §6 cl.2 + 28 USC §455(b)(3) + SOX §203
一个引擎会话在一个裁决周期内只任一职：凡起草/修改/修复过某器具（门、尺、考卷、宪法条款）者，禁任该器具所判工件的评审、验收、晋升呈报席。**修复≠认证**：修器之席永远不出该器健康证书。
- 机械判据：账本每条带 (session_id, role, artifact_sha256)；同一 sid 在同窗口以 {author|repairer} 与 {judge|certifier} 双角出现且工件集相交 = 违规成立，可单查即判。
- 失败护栏（采自魏玛教训）：此律不设"紧急状态可豁免"条款；确需兼程，走 A0 分立授权（人类逐案书面点将，落账）。

## A2 宪法分层（L-NORM-STACK）｜原型：Kelsen 效力层级 + 十二表公之于众 + 英国无分层之失
宪法文件二分：**全局核心律**（跨道通用：回执/归因/盲审/证据序等谱系律）与**项目附律**（AIHR 测试机律、边检机器注记、各项目专属条款）。附律每条须带 `derived_from: <核心条款号>`；核心无源可溯即无效，附律不得入全局文件。会话启动按项目标签装载：非该项目之附律不得注入其上下文。
- 机械判据：装配器 lint——附律缺 derived_from 或全局文件含项目专属字面（如具名测试机条款）= 启动失败；会话引导日志记「装载了哪些条款 sha256」，审计脚本断言非 AIHR 会话之上下文不含 AIHR 条款哈希。
- 失败护栏（查士丁尼/拿破仑教训）：禁注律只管**解释**不得改**效力**——允许每条款挂具名注解文件（proposals/），静默覆写禁止，解释者必须署名。

## A3 管辖路由（L-JURISDICTION-ROUTING）｜原型：Erie 判例 + 1873 司法院合并 + 28 USC §1404 + 通用 M 型 + Google monorepo 路由表
共享面只留**程序**，**实体**归各道自持：
1. 主仓、账本、门配置按路径前缀挂**道主表**（Abathur 进化道 / PCB 台架道 / AIHR 道 / border 门道），每次写入须唯一解析到道主；他席对非本道路径的写=违规（与 L-SURFACE-ATTRIBUTION 衔接：先声明后动树律此表即其机器源）。
2. 冲突消解走**优先序清单**（1873 定式）：同一事实在两级规则下有出入时，以 `superseded-by` 显式声明的一方为准；禁止两席对同一工件各出一纸互斥裁决。
3. 越界工单**转办不抛弃**（§1404 定式）：判"非我管辖"必须带目的地挂账，禁静默关闭。
4. 台架耦合须**明示承认**：PCB 量尺住在 Abathur 仓这类安排，要么写入道主表成合法托管，要么限期迁出——不许"默认住着"。
- 机械判据：pre-commit 钩子查 署名∈道主表(路径)；月度数跨道写冲突 ≥3 = 该面自动进入拆分评审；转办链可 grep 到目的工单。

## A4 托管回执（L-CUSTODY-RECEIPT）｜原型：FRE 902(13)-(14) 哈希自证 + 公共记录法处置制
凡动共享权威面（门配置、钉票集、账本状态文件）：先落**前像回执**（旧文件 sha256+可恢复引用：备份 ref/对象库 tag），后写新值，再读回对账。缺前像之改动=污染，标 DISPUTED 呈人，禁静默回滚（苏维埃档案教训：分类状态可被当权者改写，记录即失权威）。
- 机械判据：核验器按「当前哈希 == 最近回执所指」重算；不符或缺回执段 = 红。border.yaml 类外置面入一个**不可外发**的本地配置库（裸 git，永不挂远端）。

## A5 全宗分离（L-FONDS-SEPARATION）｜原型：respect des fonds（1841）+ NARA 处置表 + 保管链
一全宗一账：每道自持流水账；跨道只存**互见条目**（道名+哈希+一句话）。战役废气（转录/快照/scratch）生时盖类戳（永久证据/战役期/瞬时），永久类只准入库内 `_evidence` 语义位，战役类住仓外 TTL 目录；处置只按**处置表**留墓碑，无表删除=未授权处置（违规记录）。
- 机械判据：入库校验拒多道混条（lane 字段必须单一）；pre-commit 拒废气路径入共享仓；夜扫孤儿件=非零即红。

## B 负面清单（不该移植的）
1. bicameral 仪式化两院（苏维埃式全票橡皮章）——独立性靠谱系不靠数量；
2. 不受程序约束的秘密监察（厂卫）——监督席若无自身可核回执即非法器；
3. 小机构硬行长审计师轮换（GAO 2004 成本>收益）——采**时间隔离窗 W** 替代轮换；
4. 注释禁令（查士丁尼）——解释必然回流，只许具名不许禁；
5. 卖官（venal offices）与世袭道主——道主表变更权归人类签署条目。
