**What you'll get:** 一个名叫 Abathur（阿巴瑟，星际争霸 II 的进化大师）的进化 harness：你把任何"可进化的东西"（一个技能、一套提示词、一份配置）登记为一个基因组，它就自动循环"观察失败→反思→变异→重跑评测→择优"，每一代都是可回滚的一次提交，最终晋升永远由人拍板。它在自己身上也跑同一个循环（自我进化但碰不到自己的评分器），并且能把进化结晶打包导出、在别的机器上重新验证后嫁接（群体进化的第一步）。

**Why this approach:** 三个承重决定：(1) 被测系统与裁判分离——变异器永远写不到评测题本和计分代码，防止"自己给自己打高分"；(2) 一切以内容指纹为身份、路径全部来自配置，所以它不绑这台机器，可以在任何地方用；(3) 外部传来的"结晶"只是声明，必须在本机重跑基准才算数——这是从多臂老虎机基准线继承的诚实统计纪律。

**What it will NOT do:** 不会自动晋升任何东西（人必须确认）；不会自己改自己的评分器和保险丝；不会重新训练模型（那是 hr 的领地）；第一版不做机器间网络传输（先交付可离线交换的结晶包格式）。

**Effort:** Large
**Risk:** Medium - 主要风险在真实基准（活体 wiki 后端）的可复现性；用"玩具基因组先行 + 每次运行前强制夹具复位 + 版本探针"压到可控。
**Decisions to sanity-check:** 首个真实基因组选 historian 技能；跨机嫁接要求基准指纹逐字节相等否则隔离（v1 不设噪声容差）；自我进化的测试套件从"在位快照"运行而非候选工作树。

## Scope
### Must have
- `abathur` standalone TS CLI (Node≥22, ESM, npm-installable, bin `abathur`), border-style exit-code contract: 0 ok / 1 blocked-failed / 2 cannot-answer(inconclusive).
- **Config-driven genome registry (D7 decoupling)**: zero hardcoded workspace paths or harness names in code; genome = config record `{label, repoPath, benchSpec, budgetSpec, kernel.immutableGlobs}`; machine-specific values only in gitignored `*.local.jsonc` overlays + `$ABATHUR_CONFIG`/`$ABATHUR_HOME`; opencode binary path is config (`opencodeBin`), never a literal. **Registry (incl. train/val split) lives under the harness config home, OUTSIDE any genome repo tree — mutation diffs structurally cannot reach it.**
- **Generic `opencode-fixture-scenarios` bench adapter** (C2): per-run isolated HOME sandbox copying ONLY `.opencode/{plugin,skills,node_modules}`; opencode config COPIED + mutated (never symlink — fixes historian's plugin-isolation leak); per-run timeout owned by adapter; **deterministic fixture reset before every timed run (resetCommand, paired with seedCommand; crashed-run residue cleaned at next start)**; config-declared train/val scenario split; **opencodeBin version probed at startup, recorded in every run result + bundle provenance**; genome-declared prerequisite probes (`requires[]`); script-first scoring hook (external scorer program per unit) + optional LLM judge with family≠mutator enforced against harness-side config.
- **Deterministic built-in `toy` bench adapter** + scripted toy genome: full evolution loop testable without any model call — this is what CI/TDD and the self-bench replay use.
- **Evolution engine (C3)**: reflection mutation — mutator child session receives failed assertions + transcript digest + budgeted excerpt, proposes constrained diff; diff applied only to allowlisted paths; candidates = population, not hill-climb.
- **Selection stats (C4)**: N repeated runs per unit, per-unit score matrix, CI-based comparison vs incumbent (hr `half_width` discipline: REQUIRED per-genome {halfWidth, minEffect, nReps{initial,max}}, missing = config error), Bonferroni family_alpha=0.05 across simultaneous candidates; Pareto on (score, token-cost, turns); budget exhaustion ⇒ inconclusive, never silent pass.
- **Lineage ledger (C1/C5)**: append-only JSONL generations with content fingerprints (sha256 of canonical manifest; identity = fingerprint, never label/path; **invariance-tested: mtime/mode differ ⇒ same digest, 1-byte content change ⇒ different**), file lock for concurrent safety, crash-resume with orphan-child reaping; every generation = git commit in genome repo worktree, incumbent never destroyed.
- **Promotion gate (C6)**: `abathur promote` human-invoked only; P5 hard boundary: mutator cannot write bench assets, val split manifest, stats/adapter kernel code — enforced by allowlist AND promote-time sealed-path diff check against `kernel.immutableGlobs` AND **kernel fingerprint manifest pinned OUTSIDE the genome tree (config home), verified at every run start (`abathur kernel audit`), regenerated only at human promote**.
- **Self-evolution (C8/D6)**: engine registers its own repo as genome `abathur-self` (ships enabled); every target run appends a friction-digest record to abathur-self's candidate queue (**val-run digests content-scrubbed: counts/timings only — no val scenario text ever reaches mutator input**); `abathur run --genome abathur-self` executes queued self-candidates against **self-bench run from the incumbent-commit snapshot (read-only copy), NEVER from the candidate worktree — mutator cannot edit the tests that score it**; same promote gate; abathur-self kernel seals fitness-critical paths (stats, bench adapters, promote, ledger, kernel list).
- **Federation (C9/D8)**: `abathur bundle export [--genome --from --to]` → content-addressed offline bundle `{schema_version, digest_algo, genome_fingerprint, bench_digest, benchProvenance{opencodeVersion, adapterConfigDigest, fixtureSeedId, judgeModel, mutatorModel, nRepeats, statsConfigDigest}, generations[], evidence/}`; **bundles embed REDACTED train-only evidence files (path-masked, sha256-verifiable, 2MB/unit cap) — hashes without content prove nothing**; `abathur graft <bundle>` → candidates enter LOCAL verification queue as claims; bench_digest not byte-equal ⇒ `quarantined` (inspectable, never auto-eligible, no noise tolerance in v1); genome not registered locally or prerequisite probe fails ⇒ `pending-bench` (surfaced in status, never silently eligible); eligible ONLY after local re-bench beats incumbent. No network transport in v1 — format + commands are the commitment.
- Bilingual README (en/zh), anchor commit, `.omo` conventions.

### Must NOT have (guardrails, anti-slop, scope boundaries)
- No auto-promotion, no mutator write-access to sealed paths, no model retraining/model-benchmarking (hr owns that).
- No shipping other genome configs (VideoGen/magi/swarm adapters are future instances of the same adapter schema — v1 proves generality via toy + historian instances only).
- No opencode plugin/tool registration, no web UI/dashboard, no parallel/distributed mutation (sequential candidates).
- No federation network transport, discovery, trust layer, or auto-merge of peer lineages; no digest-divergence tolerance band in v1.
- No writes into other harnesses' repos except via generation worktrees; never write `historian/results/` style user artifacts outside sandbox; val transcripts never exported in bundles.
- No new runtime dependencies beyond zod (everything else node: builtins + git CLI + `tar` child).

## Verification strategy
> Zero human intervention - all verification is agent-executed.
- Test decision: **TDD** + `node --test` against compiled `dist/` (no experimental flags); every deterministic core module (fingerprints, ledger+lock+resume, stats, allowlist/sealed-path enforcement, fixture reset, bundle round-trip, graft quarantine) gets unit tests BEFORE its implementation lands in each todo (Implementation+Test = one todo). RED protocol under `test=build && node --test dist/test/` (tsc cannot compile references to missing modules): stub the to-be-implemented module with typed exports throwing `new Error('not implemented')` before the red run; RED = compiles, fails at runtime; then implement.
- E2E acceptance: (a) toy genome full loop headless (no model): mutate→bench→select→(simulated)promote in tmp dir; (b) real bounded run: historian genome, 1 generation, budget-capped, via `opencode run` child sessions — evidence logs kept; (c) crash-resume: kill mid-run, resume = clean ledger, orphan children reaped, exactly-once run accounting; (d) graft round-trip: export from genome A instance, import into fresh state dir, quarantine-then-rebench; (e) **fixture reset equivalence: run a mutating historian-family scenario twice back-to-back on the toy-state analogue, assert post-reset state digest equality between runs**.
- Evidence: `.omo/evidence/abathur/task-<N>-abathur-harness.*` (outside ulw-loop default).
