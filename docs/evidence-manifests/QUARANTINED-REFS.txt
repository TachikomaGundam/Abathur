# QUARANTINED-REFS — declared historical refs (INCIDENT-20261103, sibyl-20261102T202251Z-7938)
#
# One ref name per line (passed verbatim to `git rev-list`). `#` starts a comment.
#
# Meaning: commits reachable ONLY from these refs are historical artifacts, not
# active lineage. They predate .git/allowed-identities and carry author identities
# from earlier eras. The detector counts them as `quarantined_ref_commits` and does
# NOT fail on them — but this is not amnesty:
#   1. Any commit reachable from HEAD is still scanned by the HEAD pass, so if one
#      of these commits ever lands on the active lineage it fails closed.
#   2. These refs must never be pushed (`pre-push` only guards v* tags today; the
#      absence of a push guard is recorded as residual risk, not closed).
#   3. Adding a ref here is the same class of act as appending to
#      ACKNOWLEDGED-FOREIGN-COMMITS.txt: seat self-declaration is void without a
#      named adjudicator.
#
# Format: <ref> <expected-commit-count>
# The count is `git rev-list <ref> | wc -l` (ALL commits on that ref, not just the
# foreign-identity subset). The gate fails on any mismatch: a declaration it cannot
# check is worthless, and a growing backup ref must not pass silently.
#
# Verification command (replay):
#   git rev-list original/refs/heads/main | wc -l
#   git for-each-ref --format='%(refname)' | grep '^refs/original/'
