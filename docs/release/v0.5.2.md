## What changed from 0.5.1

- **Destructive-write containment**: `hygiene reclaim`, `hygiene retention`, `evidence append`, and `rules generate --out` now require a target inside a fixed root; refusals append to a hash-chained denials log.
- **Launcher run records**: each sandboxed command receives a one-hour run record (`id`, surface, root, origin, pid, leases); CLI `surface show|check` reads it back.
- **Crash reconciliation**: on CLI start, expired records whose process is gone are closed with a receipt; only leases inside the state temp root are removed; directories without a record are reported, never deleted.
- **Native plan validator**: `scripts/plan-check.mjs` replaces the removed Python validator; `abathur plan check` works again. New clauses `P-PLAN-CHECK-01` and `G-RUN-RECONCILE-01`.
- **Unused re-export removed**: `kernel/evidence/bridge.mjs`.
