# Release 0.5.4 — direct surface root follows the working directory

gate: PASS

## 为什么发这一版

0.5.3 安装后，`abathur surface show` 把 E1 根目录报成
`/home/lab/.npm-global/lib/node_modules/@tachikomagundam/abathur`，
也就是全局包自己的目录，而不是当前仓库。

后果：安装版在仓库里写文件会被当成“出界”，在包目录里写反而被当成 E1。
这是方向错误，不是显示错误。

## 修了什么

`REPO_ROOT` 从“模块所在目录”改成“工作目录所在的仓库根”：

- 从当前目录向上找 `.git`，找到的就是仓库根；
- 找不到 `.git` 时，E1 不成立，写入直接拒绝，不把家目录当工作树。

修改文件：

- `kernel/surface/index.mjs`
- `kernel/surface/containment.mjs`
- `kernel/lane/index.mjs`

新增 `test/surface-cwd.test.mjs`：

- 从仓库子目录启动 CLI，断言根是仓库根；
- 从非仓库临时目录启动，断言 `E1-NO-REPO` 拒绝。

## 怎么发

本版沿用 0.5.3 的 OIDC 通道：

- 推 `main` 和标签 `v0.5.4`；
- GitHub Actions `publish.yml` 用 OIDC 发布，生成 provenance；
- 发布后装 `@tachikomagundam/abathur@0.5.4`。
